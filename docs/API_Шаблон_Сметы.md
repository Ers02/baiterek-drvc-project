# Скачивание шаблона сметы

> **Версия:** 1.0  
> **Базовый URL:** `https://[адрес_системы]/api`

---

## Что такое шаблон сметы?

Шаблон — это Excel-файл (`.xlsx`) с заранее настроенными столбцами и выпадающими списками из справочников системы (единицы измерения, КАТО, статьи затрат, источники финансирования).

Задача пользователя: заполнить этот файл позициями закупок и загрузить обратно в систему ДРВЦ с `doc_type = "SMETA"`.

---

## Скачивание шаблона

Шаблон не требует API-ключа — он доступен публично.

```
GET /api/plans/template/download
```

В ответ сервер вернёт файл `import_template.xlsx`.

### Примеры

**Python:**
```python
import requests

response = requests.get("https://[адрес_системы]/api/plans/template/download")

with open("import_template.xlsx", "wb") as f:
    f.write(response.content)

print("Шаблон сохранён: import_template.xlsx")
```

**cURL:**
```bash
curl -o import_template.xlsx "https://[адрес_системы]/api/plans/template/download"
```

**Браузер:**  
Просто откройте ссылку в браузере — файл скачается автоматически.

## Заполнение шаблона

Откройте `import_template.xlsx`. Первый лист называется **«Позиции для загрузки»**.

### Столбцы

| № | Столбец | Обязательный | Описание |
|---|---------|:---:|---------|
| A | № | — | Номер строки (можно оставить пустым) |
| B | **Код по ЕНС ТРУ** | ✅ | Код из справочника ЕНС ТРУ |
| C | Наименование ТРУ | — | Заполняется автоматически по коду (можно оставить) |
| D | **Доп. характеристика (рус)** | ✅ | Описание на русском языке |
| E | **Доп. характеристика (каз)** | ✅ | Описание на казахском языке |
| F | Единица измерения (МКЕИ) | ✅* | Выбрать из выпадающего списка. *Для работ/услуг не обязательно |
| G | **Количество, объём** | ✅ | Числовое значение |
| H | **Цена за единицу (без НДС)** | ✅ | В тенге |
| I | Сумма (без НДС) | — | Считается автоматически: G × H |
| J | **Место закупки (КАТО)** | ✅ | Выбрать из выпадающего списка |
| K | **Место поставки (КАТО)** | ✅ | Выбрать из выпадающего списка |
| L | **Статья затрат** | ✅ | Выбрать из выпадающего списка |
| M | **Источник финансирования** | ✅ | Выбрать из выпадающего списка |
| N | Код АГСК (для СМР) | ✅** | **Только для строк со статьёй затрат «СМР»**. Если кода нет — напишите `Прайс-лист` |
| O | **Доля ВЦ (%)** | ✅*** | ***Только для работ и услуг.** Число от 0 до 100 |
| P | Обоснование (если доля ВЦ < 100%) | ✅**** | ****Если доля < 100%, обоснование обязательно** |
| Q | Сумма ВЦ (тенге) | — | Заполняется автоматически |

### Правила заполнения

**Столбцы с выпадающими списками (F, J, K, L, M):**  
Нажмите на ячейку — появится список значений. Выбирайте строго из него. Ввод произвольного текста приведёт к ошибке при загрузке.

**Код АГСК (столбец N):**  
- Если статья затрат = «СМР» → обязательно укажите код АГСК-3 из справочника
- Если кода АГСК нет (закупка по прайс-листу) → напишите слово `Прайс-лист`
- Для всех остальных статей затрат → оставьте пустым

**Доля ВЦ (столбец O):**  
- Заполняется только для работ и услуг (не для товаров)
- Значение от 0 до 100 (процент)
- Если доля меньше 100% — обязательно заполните столбец P с обоснованием

**Количество (столбец G):**  
- Для товаров — фактическое количество
- Для работ и услуг — значение `1`

## Загрузка заполненного файла

После заполнения шаблона отправьте его через API загрузки документов:

```python
import requests
from datetime import datetime

with open("filled_import_template.xlsx", "rb") as f:
    response = requests.post(
        "https://[адрес_системы]/api/external/upload",
        headers={"X-API-Key": "ВАШ_API_КЛЮЧ"},
        data={
            "doc_type": "SMETA",           # <-- обязательно SMETA для Excel-шаблона
            "bank_name": "Название проекта",
            "received_at": datetime.now().isoformat(),
            "sender_last_name": "Фамилия",
            "sender_email": "email@example.kz",
        },
        files={"file": f},
    )

print(response.json())
```

> ⚠️ При загрузке сметы всегда указывайте `doc_type = "SMETA"`.
